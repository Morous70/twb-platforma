# Jak přidat běžící text

## K čemu to je

Běžící text je řádek, který přehrávač zobrazí posouvající se přes obrazovku. Hodí se pro krátká sdělení, například „Dnes jackpot Eurojackpot 120 mil. Kč!“.

## Postup

1. V menu klikněte na **Galerie**.
2. Klikněte na dlaždici **Běžící text**.
3. Do pole **Název** napište název, například „Jackpot“. Na Google Disku se objeví jako „název.txt“.
4. Do pole **Text** napište text. Pod ním se zobrazí ukázka běžícího řádku.
5. Volitelně vyplňte **Skupinu** a **Tagy**.
6. Klikněte na **Uložit**. Objeví se hláška **Text „…“ uložen.**

[SNÍMEK: okno Nový běžící text s ukázkou]

Text pak přidejte do scénáře stejně jako obrázek, viz [Jak vytvořit scénář](jak-vytvorit-scenar).

## Jak text později změnit

V **Galerii** najděte text (filtr **Texty**) a klikněte na ikonu **Upravit** (tužka).

## Časté chyby

- **Zadejte název.** nebo **Zadejte text.** Obě pole jsou povinná.
- **Text není v kódování UTF-8.** Text obsahuje znaky, které aplikace nepřijme. Přepište ho ručně.
- **Text se nemění podle dat.** Běžící text je pevný. Pro text s proměnnými (například výší jackpotu) použijte [slide](jak-vytvorit-slide).
