# Nastavení: Upozornění

> 🔧 **Pro správce.**

Upozornění přijde při první chybě synchronizace, pak nejvýš jednou za 6 hodin, a znovu, když se vše opraví.

| Pole | Význam |
|---|---|
| **E-mail** | adresa pro upozornění |
| **Telefon pro SMS** | číslo, například `+420 777 123 456` |
| **BulkGate Application ID** | údaj z portálu BulkGate |
| **BulkGate Application token** | tajný token z portálu BulkGate (Modules & APIs → HTTP Simple API). Po uložení se nezobrazuje |
| **Uložit** | uloží údaje |
| **Uložit a odeslat zkušební upozornění** | uloží údaje a pošle zkušební zprávu |

E-mail se používá také pro odkaz k obnovení zapomenutého hesla. Viz [Zapomenuté heslo](zapomenute-heslo).

Postup: [Jak nastavit upozornění na chyby](jak-nastavit-upozorneni).
