# Nastavení: Zálohy

> 🔧 **Pro správce.**

## Část Zálohy

| Pole | Význam |
|---|---|
| **Poslední záloha** | kdy vznikla |
| **Synology** | kdy se Synology naposledy ptalo a který soubor stáhlo |
| **Automatické denní zálohy** | zapíná denní zálohování |
| **Heslo záloh** | aspoň 8 znaků, bez apostrofu. Bez hesla se nezálohuje |
| **Složka na Synology** | kam Synology zálohy ukládá |
| **Mazat na Synology zálohy starší než (dní)** | 0 znamená nemazat |

## Část Uložené zálohy

Tlačítka **Zálohovat teď** a **Obnovit ze souboru…**. U každé zálohy: štítky (**se soubory**, **jen databáze**, **před obnovením**, **nahraná**), **Stáhnout**, **Obnovit…**, **×**.

Postup a upozornění: [Jak zálohovat a obnovit data](jak-zalohovat-a-obnovit).
