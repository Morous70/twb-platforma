# Přehled karet Nastavení

> 🔧 **Pro správce.** Většina nastavení se mění jen výjimečně.

## Karty

| Karta | K čemu slouží |
|---|---|
| **Google Disk** | připojení k Google, cílová složka | 
| **Obrázky** | zmenšování a komprese obrázků, písma pro slidy |
| **Tagy** | přehled tagů, přejmenování a smazání u všech médií najednou |
| **Počasí** | služba počasí, API klíč a výchozí místo pro počasí ve slidech |
| **Přehrávač** | propojení s přehrávačem, skript pro Synology |
| **Zařízení** | plugin pro Chrome, televize Samsung a Android TV, která přehrávají stejný obsah |
| **Upozornění** | e-mail a SMS při chybách |
| **Zálohy** | automatické zálohy a obnovení |
| **Zabezpečení** | heslo, přihlášení přes Google, Passkey |
| **Systém** | verze, aktualizace, diagnostika, cron |

Popis každé karty: [Google Disk](nastaveni-google-disk), [Obrázky](obrazky-komprese), [Tagy](nastaveni-tagy), [Počasí](nastaveni-pocasi), [Přehrávač](nastaveni-prehravac), [Zařízení](nastaveni-zarizeni), [Upozornění](nastaveni-upozorneni), [Zálohy](nastaveni-zalohy), [Zabezpečení](nastaveni-zabezpeceni), [Systém](nastaveni-system).

## Ukládání

Každá karta má vlastní tlačítko **Uložit**. Pokud karty přepnete bez uložení, aplikace se zeptá: „Na této kartě jsou neuložené změny. Zahodit je?“. Změny v částech, které se ukládají samy (například **Diagnostika**), tuto otázku nevyvolají.
