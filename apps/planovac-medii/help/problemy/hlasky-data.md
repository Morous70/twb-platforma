# Hlášky u tabulky Data a zdrojů

| Hláška | Co znamená | Co dělat |
|---|---|---|
| **Řádek nelze uložit: …** | Řádek má špatné údaje. Důvod je za dvojtečkou. | Opravte údaj, například datum. |
| **Vložte řádky z Excelu (Skupina, Parametr, Hodnota).** | Pole pro vložení je prázdné. | Vložte zkopírované řádky. |
| **Nic k importu – …** | Řádky nemají aspoň tři sloupce. | Zkontrolujte oddělovače (tabulátor, středník, svislá čára). |
| **Přeskočeno: …** | Některé řádky se nepodařilo vložit. | Zkontrolujte je a vložte znovu. |
| **Zadejte název zdroje (nejvýš 60 znaků).** | Název zdroje je prázdný nebo dlouhý. | Zkraťte ho. |
| **Název zdroje nesmí obsahovat znaky { } \| : a tečku.** | Název zdroje obsahuje nepovolený znak. | Odeberte ho. |
| **Zdroj s tímto názvem už existuje.** | Název se opakuje. | Zvolte jiný. |
| **Tento název je vyhrazený pro proměnnou kalendáře.** | Název koliduje s vestavěnou proměnnou. | Zvolte jiný. |
| **Adresa musí začínat http:// nebo https://.** | Adresa zdroje má špatný tvar. | Opravte ji. |
| **Zdroj nenalezen.** | Zdroj byl mezitím smazán. | Obnovte stránku. |
| **Stažení selhalo: …** | Zdroj se nepodařilo stáhnout. Důvod je za dvojtečkou. | Zkontrolujte adresu, sdílení tabulky a formát. Slidy mezitím používají poslední úspěšná data. |
| **Zdroj uložen, ale stažení selhalo: …** | Zdroj se uložil, ale hned se nestáhl. | Totéž. Zkuste **Stáhnout teď**. |
