# Hlášky při práci s galerií a nahráváním

| Hláška | Co znamená | Co dělat |
|---|---|---|
| **Nepodporovaný typ souboru .xyz – povoleny jsou obrázky, videa a PDF.** | Soubor má jinou příponu, než aplikace přijímá. | Převeďte soubor na jpg, png, gif, webp, bmp, mp4, m4v, mov, webm, avi, mkv nebo pdf. |
| **Soubor … není platné PDF.** | Soubor je poškozený nebo nejde o PDF. | Zkuste ho znovu uložit nebo exportovat. |
| **Soubor … není obrázek ani video.** | Soubor má správnou příponu, ale je poškozený. | Zkuste ho otevřít v počítači a znovu uložit. |
| **Část souboru se nepodařilo přijmout (kód …).** | Nahrávání se přerušilo. | Zkuste nahrát znovu. Při opakování kontaktujte správce. |
| **Soubor musí být stejného druhu: …** | Nahrazujete obrázek videem nebo naopak. | Vyberte soubor stejného druhu, nebo nahrajte nové médium. |
| **Původní soubor už není k dispozici.** | Originál zkomprimovaného obrázku se nenašel. | Nahrajte obrázek znovu. |
| **Obrázek … je na zpracování na serveru příliš velký (nestačí paměť). Zmenšete ho prosím před nahráním.** | Obrázek má příliš mnoho pixelů pro server. | Zmenšete ho v počítači a nahrajte znovu. |
| **Médium nenalezeno.** | Médium bylo mezitím smazáno (třeba jiným uživatelem). | Obnovte stránku. |
| **Neplatný název.** | Název souboru je prázdný nebo obsahuje lomítko. | Upravte název. |
| **Zadejte název.** | Chybí název. | Vyplňte ho. |
| **Tag „…“ je delší než 30 znaků.** | Tag je příliš dlouhý. | Zkraťte ho. |
| **Médium může mít nejvýš 10 tagů.** | Médium už má 10 tagů. | Nějaký tag odeberte. |
| **Zadejte text.** | Běžící text je prázdný. | Napište text. |
| **Text není v kódování UTF-8.** | Text obsahuje nepodporované znaky. | Přepište ho ručně. |
| **Neplatná adresa stránky.** / **Adresa musí začínat http:// nebo https://.** | Odkaz na web má špatný tvar. | Opravte adresu. |
| **Odkaz uložen, ale pozor: …** | Odkaz se uložil, ale stránka se nenačetla. | Zkontrolujte adresu. |
| **Zadejte název náhodného výběru.** | Chybí název. | Vyplňte ho. |
| **Náhodný výběr musí obsahovat aspoň 2 obrázky, videa nebo slidy.** | Vybrali jste méně než 2 média. | Vyberte aspoň dvě. |
| **Zadejte název výběru podle data.** | Chybí název. | Vyplňte ho. |
| **Přidejte aspoň jednu položku s datem.** | Výběr nemá žádnou položku s datem. | Přidejte datum. |
| **Zadejte celé datum (den, měsíc a čtyřmístný rok 2000–2099).** | Datum je neúplné. | Doplňte celé datum a klikněte na **+ Přidat**. |
| **Neplatné datum … – rok musí být 2000–2099.** | Rok je mimo rozsah. | Opravte rok. |
| **Chybné datum (rok mimo 2000–2099) u: …** | Některá položka má špatné datum. | Odeberte datum křížkem a zadejte znovu. |
| **Nesprávný typ média.** | Pokus uložit jiný druh média pod stejnou položku. | Obnovte stránku a zkuste znovu. |
| **Zadejte název slidu.** | Slide nemá název. | Vyplňte název. |
| **Slide se nepodařilo vykreslit.** | Při vykreslení slidu nastala chyba. | Přečtěte si důvod za dvojtečkou. Zkuste zjednodušit slide, nebo kontaktujte podporu. |
| **Neplatná proměnná.** | Zápis proměnné je prázdný, příliš dlouhý, nebo obsahuje znaky `{`, `}` nebo `\|`. | Opravte zápis. |
