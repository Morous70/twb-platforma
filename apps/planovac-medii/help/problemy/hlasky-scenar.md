# Hlášky při ukládání scénáře

| Hláška | Co znamená | Co dělat |
|---|---|---|
| **Zadejte název scénáře.** | Pole **Název** je prázdné. | Vyplňte název. |
| **Vyberte aspoň jeden den v týdnu.** | U plánovaného scénáře není zapnutý žádný den. | Zapněte aspoň jeden den. |
| **Vyberte aspoň jednu hodinu.** | U plánovaného scénáře není zapnutá žádná hodina. | Zapněte aspoň jednu hodinu, nebo **Celý den**. |
| **Datum „od“ je po datu „do“.** | Období je obráceně. | Opravte data. |
| **Neplatná časová okna.** | Chyba v údajích o hodinách. | Obnovte stránku a nastavte hodiny znovu. |
| **Scénář „…“ nelze vložit – už (i nepřímo) obsahuje tento scénář. Vznikl by kruh.** | Vkládáte scénář, který by vložil zpátky ten, který upravujete. | Vyberte jiný scénář, nebo upravte vkládání. |
| **Vložený scénář neexistuje.** | Vkládaný scénář byl mezitím smazán. | Odeberte ho z **Vložených scénářů**. |
| **Scénář nenalezen.** | Scénář byl mezitím smazán. | Obnovte stránku. |
| **Scénář nemá žádná média ani vložené scénáře. Uložit i tak?** | Scénář je prázdný. | Přidejte média, nebo uložte i tak. Prázdný scénář se bere jako neběžící. |
| **Výchozím scénářem je teď „…“. Nahradit ho tímto?** | Výchozí scénář už existuje. | Potvrďte, pokud má být nový výchozí. Původní se stane plánovaným. |
| **Scénář se nepodařilo uložit: …** | Uložení selhalo. Důvod je za dvojtečkou. | Zkuste znovu. Při opakování kontaktujte podporu. |

Viz také [Jak vytvořit scénář](jak-vytvorit-scenar) a [Scénář neběží, ačkoli by měl](scenar-nebezi).
