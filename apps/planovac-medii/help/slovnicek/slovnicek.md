# Slovníček pojmů

| Pojem | Význam |
|---|---|
| **Médium** | cokoliv, co lze promítat: obrázek, video, PDF, text, odkaz, slide, HTML dokument, náhodný výběr nebo výběr podle data |
| **Galerie** | sklad všech médií |
| **HTML dokument** | stránka napsaná v editoru aplikace nebo nahraná jako soubor .html; přehrávač ji zobrazí na celou obrazovku |
| **Tag** | štítek pro třídění a hledání médií (např. Vánoce). Médium může mít víc tagů; na promítání nemají vliv |
| **Archiv** | část galerie s médii, která se už nenabízejí. Dál hrají tam, kde jsou použitá |
| **Scénář** | seznam médií s pravidly, kdy mají běžet |
| **Plánovaný scénář** | běží podle pravidel (období, dny, hodiny, výjimky) |
| **Výchozí scénář** | běží, když neběží žádný plánovaný. Může být jen jeden |
| **Pevný scénář** | zobrazuje se vždy, ke všemu ostatnímu. V konkrétním scénáři ho lze vypnout |
| **Sada** | scénář, který sám neběží, jen se vkládá do jiných |
| **Vložený scénář** | scénář, který přidává svá média do jiného scénáře |
| **Výhradní scénář** | po dobu běhu potlačí ostatní plánované scénáře |
| **Priorita** | **Nízká**, **Normální**, **Vysoká**. Rozhoduje, kdo vyhraje mezi médii ve stejné skupině |
| **Skupina (média)** | označení média v **Galerii**. Média ve stejné skupině se z různých scénářů navzájem nahrazují |
| **Skupina (data)** | název okruhu hodnot v tabulce **Data**, například „Sportka“ |
| **Parametr** | druhý sloupec v tabulce **Data**: datum nebo text, podle kterého se hodnota hledá |
| **Výjimka** | den, kdy scénář neběží |
| **Slide** | obrázek vytvořený v aplikaci, jehož texty se mohou měnit |
| **Grafický styl** | vzhled textu ve slidu se září, stínem, 3D hloubkou, obrysem a výplní přechodem (například Zlato) |
| **Proměnná** | zástupný text ve složených závorkách ve slidu, například `{datum}`. Aplikace ho nahradí hodnotou |
| **Zdroj (dat)** | data stažená z internetu (JSON nebo CSV), která slidy používají |
| **Passkey** | přihlášení otiskem, obličejem nebo PINem zařízení, bez hesla. Zařízení se registruje v **Nastavení → Zabezpečení** |
| **Odkaz pro obnovu hesla** | jednorázový odkaz z e-mailu, platí 30 minut. Slouží k nastavení nového hesla |
| **Náhodný výběr** | několik médií, z nichž se každou hodinu zobrazí jedno |
| **Výběr podle data** | média, která se zobrazí jen ve zvolené dny |
| **Komprese** | zmenšení obrázku. Originál zůstává uchovaný |
| **Google Disk** | úložiště, do kterého aplikace ukládá soubory pro televizi |
| **Cílová složka** | složka na Google Disku, kterou čte přehrávač |
| **Synchronizace** | úprava cílové složky podle aktuálního plánu a pokyn přehrávači |
| **Cron** | pravidelná úloha na serveru, která spouští synchronizaci a další činnosti (zhruba každých 5 minut) |
| **Přehrávač** | zařízení, které promítá obsah na televizi (SlideShow) |
| **Plugin pro Chrome** | doplněk prohlížeče Chrome, který přehrává stejná média jako obrazovka v trafice. Přidává se v **Nastavení → Zařízení** |
| **Párovací kód** | šestimístný kód na obrazovce televize. Zadává se v **Nastavení → Zařízení → Spárovat televizi**, platí 10 minut |
| **Klíč zařízení** | heslo, kterým se plugin připojuje k aplikaci. Umí jen číst. Zobrazí se jen jednou |
| **Synology** | zařízení v místní síti, které předává přehrávači pokyn ke stažení a stahuje zálohy |
| **Záloha** | šifrovaná kopie všech dat aplikace |
| **Protokol** | záznam činnosti a chyb aplikace |
| **Diagnostika** | kontrola, že všechno potřebné funguje |
