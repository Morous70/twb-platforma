# Co aplikace umí

TWB Media galerie je soukromá galerie obrázků a videí pro vaše vlastní kampaně. Používá ji jeden správce.

- **Přehled** ukazuje, kolik máte obrázků a videí a kolik místa zabírají.
- **Galerie** je místo, kam média nahrajete (i velká videa) a kde je spravujete: tagy, archiv, nahrazení souboru, komprese.
- **Kampaně** jsou složky, do kterých média roztřídíte.
- **Nastavení** obsahuje zabezpečení: heslo, e-mail pro obnovu hesla, automatické odhlášení, Google a Passkey.

Každý soubor má **veřejný odkaz** pro vložení na web. API a zálohy přibudou v dalších verzích.
